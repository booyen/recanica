# Rekanica · Next.js marketing starter

A full landing page built only from Rekanica blocks: navbar, product hero, logo cloud, features, bento, testimonials,
pricing, FAQ, CTA and footer. Switch the brand finish with `data-finish="mesh"` on `<html>` in `app/layout.tsx`.

```bash
npx degit booyen/rekanica-des/templates/next-marketing my-site
cd my-site && npm install && npm run dev
```
