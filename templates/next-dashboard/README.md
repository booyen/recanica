# Rekanica · Next.js dashboard starter

Polar-style app shell: sidebar with sub-nav (sheet on mobile), fixed inset panel, grouped stat panels.

```bash
npx degit booyen/rekanica-des/templates/next-dashboard my-app
cd my-app && npm install && npm run dev
```

Add more screens from the pattern library:

```bash
npx rekanica add data-table
npx rekanica add invoices-01
```
